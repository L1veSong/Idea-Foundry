# 论文需求逼问方法论

> 从 design-grill-methodology.md 的 8 维模型适配而来。用于论文写作前的需求提取——在动笔之前，逐项逼问暴露盲区和隐藏需求。已验证：教育学会论文（2026-06-05）。

## 核心原则

论文不是设计方案——没有"依赖失效"或"自毁风险"。8 维需要重新映射：

| 原维度 | 论文适配 | 核心问题 |
|--------|---------|---------|
| 依赖失效 | **素材来源** | 论文的案例/数据从哪来？没有真实案例怎么办？ |
| 数据过期 | **多篇差异化** | 同时写多篇如何避免内容重叠？边界在哪？ |
| 能力边界 | **案例真实性** | 评委如何判断是不是AI写的？有没有不可替代的个人细节？ |
| 组合效应 | **格式规范** | 通知/模板里每个格式要求都落实了吗？缩进、字体、字号？ |
| 资源浪费 | **字数控制** | 往多了写还是往精了写？硬凑字数 vs 内容优先？ |
| 规则膨胀 | **署名/单位** | 怎么写？通知有没有特殊要求？ |
| 脏数据 | **参考文献** | 需要吗？真实可查吗？格式对吗？ |
| 自毁风险 | **提交确认** | 文件名、格式、查重都满足吗？有没有遗漏项？ |

## 逼问流程

```
1. 读取所有格式要求文件（PDF + 图片），逐条提取规范
2. 对 8 个维度逐项逼问，每个必须用 clarify() 给出选项
3. 用户可能中途暂停——允许，下次从暂停处继续
4. 全部逼问完成后，输出决策汇总表
5. 创建 plan 文件（task_plan.md + findings.md + progress.md）
6. 列大纲 → 搜参考文献 → 用户确认 → 开工
```

## 8 维逼问模板

### 维度 1：素材来源
```
核心问题：论文的案例/数据从哪来？
选项示例：
- 有真实活动经验，可以给我口述细节
- 没有现成案例，你根据专业规律合理设计（但必须像真的）
- 你设计活动框架+案例，我看了再改
```

### 维度 2：多篇差异化
```
核心问题：同时写多篇如何避免内容重叠？
选项示例：
- 第一篇叙事型，第二篇分析型
- 第一篇按年级分层，第二篇按领域展开
- 第一篇理论+案例，第二篇实施方案+反思
```

### 维度 3：案例真实性
```
核心问题：评委如何判断不是AI写的？
对策：
- 必须有不可替代的个人细节（"我们班XX小朋友……"）
- 引用真实发生过的活动（哪怕一句话描述）
- 参考文献真实可查
```

### 维度 4-8
```
格式规范、字数控制、署名、参考文献、提交确认——
逐项按通知要求，每一项都用 clarify 确认，不假设。
```

## 实战案例：教育学会论文（2026-06-05）

- 素材：风筝节 + 各节气活动 + 小雪腌咸菜
- 两篇差异化：写两篇，用户选一篇提交
- 格式：按通知附件1（标题3号黑体、正文小四宋体、每段缩进2格……）
- 署名：按通知要求
- 参考文献：需要，按通知格式
